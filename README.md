## ⚡ Overview
The official community web hub and creator portal for **Krylo's Skybase** and **KryloSMP**.
Built from the ground up with native Discord Open Graph (OG) integration for rich visual preview cards.

## 🌟 Key Features
- **Discord Rich Embeds:** Complete Open Graph metadata (`og:title`, `og:image`, `theme-color: #00E5FF`).
- **Minecraft Server Integration:** 1-Click IP copying for `krylosmp.falix.gg:29273`.
- **Ecosystem Portals:** Quick access to the Official Web Store, Krims Code AI Bot Dashboard, and Film Crew Auditions.
- **Ultra-Lightweight & Fast:** Responsive, zero bloat, mobile-optimized glassmorphism UI.
